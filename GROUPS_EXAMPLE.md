# Window Groups (Табы) в HyprWin

Window groups позволяют группировать несколько окон в одно пространство с табами, как в браузере или tmux.

## Как это работает:

- Окна в группе **занимают одно место** в layout
- Между окнами можно переключаться через **табы** (отображаются сверху окна)
- Только **одно окно активно** в группе, остальные скрыты

## Команды для groups:

```lua
-- Добавить примеры биндингов в ваш конфиг:

-- Создать группу с текущим окном
hl.bind("SUPER + G", hl.dsp.group.new())

-- Добавить текущее окно к группе соседа
hl.bind("SUPER + SHIFT + G", hl.dsp.group.add())

-- Toggle: добавить/убрать окно из группы
hl.bind("SUPER + T", hl.dsp.group.toggle())

-- Переключение между табами в группе
hl.bind("ALT + Tab", hl.dsp.group.cycle_next())
hl.bind("ALT + SHIFT + Tab", hl.dsp.group.cycle_prev())

-- Убрать текущее окно из группы
hl.bind("SUPER + CTRL + G", hl.dsp.group.remove())
```

## Визуализация:

```
┌─────────────────────────────────────┐
│ [Tab1] [Tab2*] [Tab3]              │ ← Tab bar (28px)
├─────────────────────────────────────┤
│                                     │
│      Активное окно (Tab2)          │
│                                     │
│                                     │
└─────────────────────────────────────┘
```

- **Активный таб** подсвечен accent цветом
- **Неактивные табы** затемнены
- Табы показывают **заголовок окна** (обрезан до 20 символов)

## Use cases:

1. **IDE + Terminal**: Группируй VS Code с терминалом в одном тайле
2. **Browser tabs**: Несколько окон браузера в одной группе
3. **Документы**: Word/Excel/PDF в одной группе для быстрого переключения

## IPC команды:

```bash
# Добавить в группу
echo "dispatch group add" > \\.\pipe\hyprwin

# Переключить таб
echo "dispatch group cycle_next" > \\.\pipe\hyprwin
```

Эта фича портирована из **Hyprland** и работает идентично!
